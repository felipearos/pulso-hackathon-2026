## Key decisions
- Git exports GIT_DIR and related variables to hooks run from linked worktrees. Because of that, the hook's trial merge in its temp worktree actually ran against the pushing worktree. `.githooks/pre-push` now unsets GIT_DIR, GIT_INDEX_FILE, GIT_WORK_TREE, GIT_PREFIX and GIT_COMMON_DIR once it has resolved the repo root.
- New `src/pre-push.test.ts` reproduces the bug with a scratch origin and a linked worktree. It failed on the old hook and passes on the new one. The test env sets GIT_CONFIG_GLOBAL and GIT_CONFIG_SYSTEM so the user's git config cannot leak in (a standards-review finding, fixed by hand).
